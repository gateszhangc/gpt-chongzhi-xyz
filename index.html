Keep billing clear

ChatGPT plans and API usage are separate.

A ChatGPT subscription upgrades the ChatGPT product. API usage has its own billing, so an individual ChatGPT plan does not add API credits.

Quick answers

GPT recharge questions, answered.

Where should I check current ChatGPT plans?

Use the current ChatGPT pricing page. It is the best place to compare plans, features, and availability before purchase.

Is ChatGPT API usage included in a ChatGPT subscription?

No. ChatGPT subscriptions and API usage are billed separately.

What should I do if I was charged but my plan did not update?

Confirm the purchase account, restore mobile purchases when applicable, refresh the account state, and then contact official billing support with the receipt.

Should I rely on a saved plan comparison?

No. Plan features and limits can change, so compare the live pricing page when you are ready to purchase.
